# Long-Term Portfolio Optimization and Risk Analysis

**Project Overview**
This project models long-term investment strategies by analyzing historical financial data of various asset classes (e.g., S&P 500, bonds, gold). The goal is to determine the optimal asset allocation that maximizes returns while minimizing risk, providing a practical, data-driven tool for long-term financial planning.

**Applied Numerical Methods**
To satisfy the course requirements, this project implements three distinct numerical methods:
1. **Gradient Method / Minimum Finding:** Applying the Markowitz portfolio theory by using gradient descent to find the global minimum of the portfolio variance (risk).
2. **Data Fitting & Error Propagation:** Fitting exponential and polynomial trend lines to historical asset prices to forecast long-term growth, while calculating the associated uncertainties and prediction errors.
3. **Eigenvalues and Eigenvectors:** Performing Principal Component Analysis (PCA) on the covariance matrix of asset returns to identify underlying market factors and verify the mathematical validity of the diversification.

**Task Breakdown**
* Data acquisition and preprocessing from historical CSV files.
* Implementation and fine-tuning of the three numerical algorithms.
* Scientific analysis of model stability, convergence parameters, and methodological limitations.
* Visualization of the efficient frontier, trend lines, and correlation heatmaps.
